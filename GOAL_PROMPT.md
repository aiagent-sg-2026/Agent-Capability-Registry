# Continuation goal

Keep the registry local-first and evidence-driven. Preserve fail-closed permissions, deterministic verification, atomic installs, and no package execution. Extend only with tests and narrowly scoped adapters; defer remote services and LLMs until a concrete contract exists.

The bounded Package Factory is the narrow exception for the verified demo contract: the shared `github-pages` registration is temporary, dedicated gateway project/origin registration is preferred, and only candidate evidence is persisted.

Continuous Factory V1 uses an append-only opportunity queue and persists only data-only `CANDIDATE_ONLY` packages. No production deployment is claimed.
