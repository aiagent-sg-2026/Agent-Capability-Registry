How an AI agent learns reusable capabilities automatically.

ACR turns small AI-generated knowledge packages into a searchable, evidence-gated capability registry. The Factory discovers work, proposes a package, validates it, reviews it, retries bounded failures, and stores safe CANDIDATE_ONLY context for Codex or Pi.

06 / AGENT TASK LOGIC

How Codex / Pi uses ACR

User task“Review this PostgreSQL reporting query”
  1. ResolveReduce task to catalog-relevant terms.
  2. SearchRank matching capabilities deterministically.
  3. InfoRe-check exact name/version and evidence.
  4. SelectPick highest-ranked valid candidate.
  5. UseBuild a bounded context-only bundle.
  6. RunLaunch Codex or Pi with original task unchanged.

07 / SAFETY

Trust boundaries

CANDIDATE_ONLYAI generation never becomes trusted automatically.
executable = falseCapability content is reference data, not commands.
No auto-installSearch/use does not install packages or hooks.
Read-only defaultAgent runner defaults to a read-only workspace.
Sanitized public dataDashboard excludes local paths, prompts, content and credentials.

08 / 7-DAY VIEW

If the Factory is left running for a week

672maximum timer opportunities
7 days × 24h × 4 cycles/hour

Actual capability growth will be lower. Cycles may discover opportunities, retry malformed/unsafe candidates, hit review gates, or find nothing new. The goal is durable quality, not consuming the daily token budget.
